# VisionGuard coursework interface

Scope: refine the existing Flask upload, result, history and friendly-error templates. Mode: Operate. The assignment explicitly asks for a simple HTML/CSS interface; retain its existing flow and factual model caveats. No new brand, assets or marketing surface is required.

## Direction contract

THESIS: make an image check understandable in one glance, with a clear route from upload to verdict to saved history. Preserve the native form-based structure.

OWN-WORLD: white content, cool light-gray surrounding surface, dark blue-gray text and restrained blue actions; system sans; modest corners and fine rules, without decorative illustration.

STORY: choose a PNG/JPEG, submit it, read an uncertain AI/Real estimate, and find the saved metadata later. Errors explain recovery. Images are not stored.

FIRST VIEWPORT: compact wordmark/navigation above a generous main content area; upload form is the main action with a short explanatory aside. Results make verdict, confidence and caveat prominent. History is a readable responsive table.

FORM: scoped refinement of the existing semantic HTML forms and table; no direction roll applies to this precise, existing coursework flow. The user confirmed the simple scope and direct HTML/CSS implementation. The code-first workflow is recorded in .impeccable/config.json.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
